# thinceller-claude-plugins

A collection of Claude Code marketplace plugins.

## Installation

Add this marketplace in Claude Code:

```
/plugin marketplace add thinceller/claude-plugins
```

Then install a plugin:

```
/plugin install git-toolkit@thinceller-claude-plugins
/plugin install engineering@thinceller-claude-plugins
```

## Plugins

- **git-toolkit** - Streamlines git workflow (auto-commit, PR creation, merge/rebase conflict resolution)
- **engineering** - Loosely-coupled software engineering skills (interview-driven design, spec/plan writing, subagent implementation loops, debugging, TDD, review disciplines)
