# 平易な言い換え

言い換えの候補集。文脈に合うものだけを選ぶ。表を機械的に置換すると、かえって意味がずれる。

## 即席の漢語をほどく

| 避ける | 言い換え |
| --- | --- |
| 粒度感 | どこまで細かいか |
| 認知負荷 | 読む人の負担 |
| 可読性が低い | 読みにくい |
| 最適化する | 短くする、速くする、無駄を省く（何をしたかを書く） |
| 体験設計 | 使い心地をどう作るか |
| 言語化する | 言葉にする、書き出す |
| 網羅的に | もれなく |
| 横断的に | 複数の部署（システム、章）にまたがって |
| 抜本的な | 大きく変える、作り直す |
| 蓋然性が高い | ありそうだ、起きやすい |
| 〜性 | 〜かどうか、〜しやすさ |
| 〜化する | 〜にする、〜になる |

## カタカナ語

| 避ける | 言い換え |
| --- | --- |
| アサインする | 割り当てる、担当を決める |
| エビデンス | 根拠、証拠 |
| コンセンサス | 合意 |
| プライオリティ | 優先順位 |
| バッファ | 余裕 |
| リソース | 人手、時間、予算（何を指すかを書く） |
| ペンディング | 保留 |
| イシュー | 論点、課題 |
| ナレッジ | 知見 |
| フィジビリティ | 実現できるかどうか |

分野で定着している技術用語（API、ログ、キャッシュ、デプロイ、リポジトリ）は、そのまま使う。読者がその分野の外にいるときだけ、初出で一度説明する。

## 硬い書き言葉

| 避ける | 言い換え |
| --- | --- |
| 〜に関しまして | 〜について |
| 〜という点において | 〜では |
| 〜のような形で | 〜として、〜で |
| 実施する | する、行う |
| 利活用する | 使う |
| 〜に鑑みて | 〜をふまえて |
| 可及的速やかに | できるだけ早く |
| 〜の旨 | 〜ということ |

## 翻訳調

| 避ける | 言い換え |
| --- | --- |
| 〜することができる | 〜できる |
| 〜する必要がある | 〜する、〜しなければならない |
| 〜において重要な役割を果たす | 何をするのかを具体的に書く |
| 私たちは〜と考える | 主語を省いて「〜と考えます」 |
| それは〜を意味する | つまり〜 |
| 〜のうちの一つ | 〜の一つ |

## before / after

**造語と長い一文**

- before: 本施策は、ユーザー体験の最適化を目的として、情報設計の粒度感を再定義し、認知負荷の低減を図るものである。
- after: この施策の目的は、画面を使いやすくすることです。項目をどこまで細かく分けるかを見直し、読む人が一度に覚える量を減らします。

**予告と水増し**

- before: 重要なのは、本ドキュメントにおいて、レビュープロセスの改善について多角的に検討していくという点です。まず前提として、現状のレビューには課題が存在しています。
- after: レビューを二段階に分けます。今は一人のレビュアーが設計と実装を同時に見ているため、指摘が実装の細部に偏っています。

**係り受けが遠い**

- before: 昨日の会議で決まった来月から適用される新しい経費精算のルールについて、経理部から共有された資料をもとに各部署の担当者が説明を行う必要がある。
- after: 経費精算のルールが来月から変わります。昨日の会議で決まりました。各部署の担当者は、経理部が配った資料をもとに説明してください。
